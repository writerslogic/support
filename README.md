# WritersProof Support

Public issue tracker and support for **WritersProof** — cryptographic proof-of-authorship for macOS.

- **Report a bug:** [open a bug report](https://github.com/writerslogic/writersproof-support/issues/new?template=bug_report.yml)
- **Ask for help or request a feature:** [open a support request](https://github.com/writerslogic/writersproof-support/issues/new?template=support_request.yml)
- **Private or sensitive matters:** support@writerslogic.com
- **Website:** https://writerslogic.com

When reporting a bug, please include your **WritersProof version** (Settings → About), your **macOS version**, and clear **steps to reproduce**.
